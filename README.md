# Mental_Health-Project

A machine learning-based web application that predicts a student's **Mental Health Score (0–10)** based on social media usage, academic activities, lifestyle habits, and perceived stress.

The project combines a trained machine learning model with a **FastAPI backend** and a responsive **HTML/CSS/JavaScript frontend**.

---

## 📌 Project Overview

Social media usage, study patterns, sleep, physical activity, and stress levels can influence a student's overall well-being.

This project provides an interactive web interface where users can enter information about their daily habits and receive a predicted mental health score.

The application is intended for **informational and educational purposes only** and is **not a clinical or medical assessment**.

---

## ✨ Features

- Predicts a mental health score from **0 to 10**
- Interactive web-based interface
- Machine learning prediction using a trained model
- FastAPI REST API
- Responsive frontend
- Social media usage analysis
- Academic and lifestyle factor analysis
- Perceived stress level input
- Visual score gauge
- Score interpretation:
  - **Signal: strained**
  - **Signal: balanced**
  - **Signal: strong**
- Error handling and validation
- Supports repeated predictions without restarting the application
